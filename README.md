# Naqsh website pack

Drop this whole folder into the project root, open it in your coding agent, and send:

> Read PROMPT.md and follow it. Start with Step 0 (read everything and send me a plan). Do not write code until I approve the plan.

## Before you start
- Add the client's photos to `assets/images/` (see `assets/images/README.md`). No photos yet? That's fine, the build uses placeholders.
- Check `docs/08-open-items.md` and send the client the questions.
- Change anything in `docs/DECISIONS.md` that you decide differently (stack, CMS, languages).

## Files
- `CLAUDE.md` project rules, read every session
- `PROMPT.md` the master build prompt
- `docs/` brief, sitemap, content, design system, inspiration, motion, technical spec, open items, progress log, decisions
- `design/tokens.css` colors, type, spacing, motion tokens
- `assets/logo/` wordmark and emblem in SVG and PNG (black, ivory, copper, copper-gradient)
- `assets/pattern/` diamond-lattice background pattern
- `reference/` client files, moodboard, palette, hero inspirations, original logos
