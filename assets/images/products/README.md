# Product photos

Upload the client's 21 product photos into this folder: `assets/images/products/`.

Use the matching filename from `docs/products.json` (for example, `excellence-award.jpg`). Keep the product names as listed in `docs/09-product-catalogue.md`. WebP or AVIF is preferred for the finished website; JPG and PNG are also accepted. If using another format, update that product's `image` value in `docs/products.json`.

If the supplied files already have different names, place them here unchanged and provide the matching product name for each file. Do not guess a match from filenames alone; uncertain matches need client confirmation. Extra views can use `<slug>-02.webp`, `<slug>-03.webp`.

Each product should have one clear, well-lit photo, ideally a 4:5 portrait crop. Please also provide descriptive alt text or enough context to write it accurately. Do not add prices, package contents, sizes, or other product claims unless the client supplies them.
