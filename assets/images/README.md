# Images

Put client photos here. Until they arrive, the build uses the `Placeholder` component (no stock, no hotlinks).

## Folders
- `hero/` full-screen hero photo. Desktop 2560x1440 (16:9), mobile crop 4:5 or 9:16. Subject right of center, empty space on the left for text.
- `collections/` one set per collection slug: `new-hire-welcome-kits-01.webp`, `client-packages-01.webp`, `ramadan-eid-baskets-01.webp`, `annual-event-giveaways-01.webp`, `brand-souvenirs-01.webp`, `appreciation-gifts-01.webp`, `custom-occasion-gifts-01.webp`. Card ratio 4:5, wide band 21:9.
- `placeholders/` generated placeholder art only.

## Style
Warm daylight, soft window shadows, natural materials (linen, paper, clay, leather, cork, copper, wax),
palette-matched (terracotta, sage, ivory, black). No harsh flash, no glitter, no cluttered bows, no staged smiling stock people.

## Export
WebP or AVIF, hero under about 300 KB, cards under about 150 KB. The hero image loads with priority.
Add descriptive alt text for each image in the CMS or data file.
