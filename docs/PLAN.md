# Build plan (written by the agent, autonomous run)

## Stack
- Next.js 16.4 (App Router, Turbopack) + React 19 + TypeScript strict.
- Tailwind CSS v4 (CSS-first `@theme` mapped to `design/tokens.css` values; no new colors).
- Lenis + GSAP (ScrollTrigger, SplitText) for motion, wired once in `MotionProvider`.
- `next/font/google`: Cormorant Garamond (400, 500) + Manrope (400, 500, 600).
- `next/image` with AVIF/WebP; optimized masters generated by `scripts/optimize-images.mjs` (originals untouched).
- Inquiry: react-hook-form + zod (client and server), `POST /api/inquiry`, Resend (logs to console in dev when no key).
- CMS: Sanity. Website reads through `src/lib/cms.ts` (next-sanity client). Falls back to `src/content/*` when the
  project ID is missing or a query returns nothing. Studio lives in `sanity/` as a standalone project (own package.json)
  so the website build stays lean.
- `cacheComponents` / `partialPrefetching` turned **off** (scaffold default on). Classic static rendering + `revalidate`
  is simpler for a marketing site and avoids Suspense requirements around CMS reads. Logged in DECISIONS.md.

## Motion approach
- Markup is server-rendered and fully visible without JS. A tiny inline script adds `html.js`; reveal start states
  are applied only under `.js` and only when motion is allowed, with a 2.5s safety timeout that reveals everything.
- One client `ScrollEffects` component scans `[data-reveal]` (fade-up, lines, words, clip, draw, stagger, parallax)
  per route inside `gsap.context`, reverted on route change. Pinned Approach steps are desktop + fine-pointer only.
- `prefers-reduced-motion`: no Lenis, no parallax/pin/scrub; content shown immediately.

## Conflicts found and how they were resolved (details in DECISIONS.md)
1. Sitemap puts the terracotta CTA directly before the black footer (two colored blocks adjacent). Resolution: the CTA
   is a large terracotta panel inset in an ivory section, so a band of ivory always separates it from the footer.
2. Wax seal = terracotta circle, but it sits on the terracotta CTA. Resolution: on terracotta the seal uses a chestnut
   wax body with a terracotta inner ring.
3. Docs say Cormorant 400/500 only but mention "Cormorant light" in the hero. Resolution: 400 (already light-looking).
4. Two product photos are swapped by filename (`wellness-kit.png` shows the Independence Day set and vice versa).
   Resolution: mapped by content, originals untouched, flagged in open items.
5. No dedicated hero or collection photos. Resolution: best-fitting product photos used (see IMAGE-MAP.md).
